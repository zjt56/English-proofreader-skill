# 教辅版面感知与优先检查

本文件用于四步流程中第二步的结构识别及第三步的版面审查；读取路径先按 [读取与结构分流](proofreading-workflow.md)选择。教辅中的横线、下划线、括号和空白通常是题目设计的一部分，不能按普通文章的空格处理。

## 先识别题型和区域

在检查英文之前，先给每页或每个题组标注可见结构：

- 目录/索引：条目、层级或字母排序、页码、对应正文标题/词条和收录范围。
- 词汇/背记册：词条号、单词、音标、词性、中文释义、派生词、短语和例句；附表逐行/逐列保持对应。
- 单项选择：题号、题干、A/B/C/D 选项、作答括号或答案位置。
- 多项选择：题号、题干、选项集合、是否注明“多选/有多个正确答案”。
- 填空/单词拼写：题干、下划线/长横线、括号内提示词、词形要求。
- 语法变式/句型转换：原句、转换要求、答题线、括号或关键词提示。
- 阅读/完形/语篇：文章正文、题号、选项、题干和与文章对应的答案区域。
- 作文/写作：提示语、写作要求、词数/时态/人称要求、网格线或横线区域。
- 讲解/例句：标题、规则说明、例句、中文释义；这里没有学生答题空格，须按普通语言文字核查。

如果页面同时有两栏或多个题组，先确认阅读顺序和题组边界，再开始校对。横线、下划线、空白括号和作文格线默认标记为 `<ANSWER_BLANK>`，不得在语言检查中展开或拼接。

## 多栏、表格与上下分节的读取

先按 bbox 识别空间结构，再判断阅读顺序。栏数不是固定参数：索引可有5栏、7栏等；“四个区域”也可能是上下两节各双栏，三列表格应逐行对应，不能把每列当独立文章。

可用 `prepare_review.py --pages 1,49 --no-render` 小样提取（页号须在实际文件范围内），保留 `lines[].bbox/text/spans.font`、`column_count`、`regions`。坐标单位为 PDF 点，原点左上；不是渲染图像的像素。

自动判栏思路：从文本行的 x 区间作横向占据统计，找在多行持续出现的空白栏沟，再用行左缘聚类辅助核对；页眉、侧栏、缩进词、词性/音标字段、跨栏标题、长装饰线会制造假边界。脚本当前采用空白条带候选法，排除竖排和纯私用区行参与提议，保留这些对象供检查，不自称通用版面恢复器。`layout_status=unverified` 始终表示尚需代表原页确认。`column_count` 是区域候选栏数的最大值，不是已认证的全页逻辑结构。

确认时对照首/中/末词条、跨行短语、栏尾页码、标题上下区和附表，检查漏字/串栏；自动方案不符时用 `--layout-config` 指定不重叠 `regions[].bbox`、非等宽 `column_breaks`、`reading_order=column/row`。结构变化处另分 y 区域；见 [配置样例](../examples/layout-config.json)。数字 `--columns N` 仅用于经确认的等宽栏，不能把其他 AI 的“5栏”直接当测量结果。当前页仍有 `unassigned_lines` 或大量 `crossing_lines` 时先调整或看图，不做“全书找不到”的结论。

`text` 由独立行以换行隔开，不把相邻栏硬拼接。行记录和字体片段是可追溯底稿；同一短语可能因原PDF分字保存在多条行中，须结合 bbox/基线/词条边界恢复，不能从换行推断词尾缺失。`rows` 额外给同区域同栏、近基线片段的组合候选及 line_ids，保留原 lines，不自动把续行页码或另一词条并入词头。`auxiliary_lines` 保留纯私用区或非横排对象，先判功能，不能默认都是装饰或直接删除。复杂合并单元格/嵌套表仍需图像核对。

### 分组后核序号

正文从上一天续页、下半页开启新一天时，以可见 Day/节标题和前后页承接划组，再在组内连续校验。例：同页第37天 `3. insect` 和第38天 `3. athlete` 不重号；第37天内部两条均标3且非引用/子层级才是重号候选。不得按页全局查重，也不能见重复序号就自动创造新组。跨栏、跨页维持同组，未知组边界先回看标题。

## 固定检查顺序

### 1. 题号和序号

- 从页首到页尾检查题号是否连续、重复、跳号、错层级或与答案页/解析编号不一致。
- 检查题号后的句号、点号、括号、破折号、冒号等是否符合该题型和全稿体例；只报告会造成识别、检索或题意问题的差异。
- 检查小题号、括号序号、语篇空格编号与题干/答案是否一一对应。

### 2. 选项和答案结构

- 单项选择通常应能读出 A、B、C、D 四个选项；检查是否缺项、重复、错序、题号错配、选项文字串入相邻题或选项符号不一致。
- 选项数量依实际题目设计判断；干扰选项、错误辨析和改错题中的待纠正句可能有意不正确，先核题目及解析是否成立，不能把每个非正确答案都报成语言差错。
- 多项选择须核对题干是否说明选择数量/范围；不能因为存在多个选项就直接判题目错误。
- A/B/C/D 前后的空白、横线和换行是版式，除非遮挡、截断或使选项无法辨认，否则不报告为空格错误。
- 答案表只用于结构对照，不能代替先独立作答。答案与题号对应错误属于“题目/答案/解析”；选项内容本身的语言错误按语言类别归类。

### 3. 题干、文章和解析的语言

- 只检查已经印出的文字：拼写、词形、主谓一致、时态、语态、代词、冠词、单复数、介词、搭配、从句、句子边界、标点和大小写。
- 题干中的挖空线、下划线、答题格和括号内待填位置不作为句子缺词或空格错误；只有题干本身在不填答案时已经违反语法或标点规则，才报告问题。
- 对句型转换/语法变式，核查“原句 + 转换指令 + 已印出的关键词/提示词”的语法和标点；答题线中的预期答案不在稿件中时，不猜测学生答案。
- 作文题检查题目要求、时态、人称、词数、标点和提示语是否自洽；作文书写格线、横线和空白区域不作为排版错误。

### 4. 题目、答案、解析对应

- 题目先独立作答，再核对答案页；检查题号、选项标签、词形和变式答案是否对应。
- 解析必须解释题干中已印出的语言点；不能因为答题线的长度、空白宽度或下划线数量与答案长度不同而判错。
- 只有能证明漏题、重复题、答案错位、题目无解/多解或解析推理不成立时，才列为题目/答案/解析问题。

## 允许报告和禁止报告的边界

| 版面对象 | 可以报告 | 不得报告 |
|---|---|---|
| 题号 | 重复、跳号、错层级、与答案/解析错配 | 题号与正文之间的正常空白 |
| 选项 | 缺 A-D、重复标签、错序、选项被截断或串题 | A/B/C/D 之间的空白、换行、排版间距 |
| 填空线 | 遮挡题干、截断文字、题号与空格错位到另一题 | 下划线、长横线、括号内空白本身 |
| 句型转换 | 原句或转换指令有语法/标点错误 | 答题线长度、空格数量、未印出的学生答案 |
| 作文格线 | 提示语、词数或要求冲突，格线遮挡文字 | 格线、横线、书写空白本身 |
| 文章正文 | 常识性语法、拼写、标点、指代、逻辑错误 | 因换行、分栏或字间距产生的 OCR 空格差异 |

## 输出分类

优先使用以下错误领域，避免把所有问题归为“格式/空格”：

1. `题号/序号结构`
2. `选项结构`
3. `语法/句法`
4. `拼写/词形`
5. `标点/大小写`
6. `题目/答案/解析对应`
7. `版面遮挡/截断`
8. `材料不足/原图待核`

每条都写出：文件页、题号/题型、错误领域、具体错误类型、印出原文、建议改为、判定理由。答题线和空白区域没有错误时，不创建问题条目。
