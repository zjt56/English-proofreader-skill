# 差错与体例的判定优先级

适用于“形式是否成立”与“是否违反本稿规则”两种判断。发现系统性现象、词条缺要素或规范冲突时使用；无需为普通拼写错例载入全部出版资料。

## 先确认规则，再定性

| 顺序 | 判断 | 处理与例子 |
|---|---|---|
| 1 | 原图是否确有该现象，文本功能是什么 | `leave ou` 的原图若是 `leave out`，属于抽取故障；填空横线、干扰项、字形编码异常先排除，不进入稿件差错数 |
| 2 | 规则是否真实、适用，是否有明确例外 | 核对规范原文、适用语境、版本及强制/推荐性质。参考指引或模型记忆不能替代条文。中文释义内标点与英文例句内标点分开判断；Unicode 半角码不证明印刷字形宽度违规 |
| 3 | 当前委托是否明确指定体例或例外 | 委托范围优先；明确指定的表达体例优于技能默认习惯。若与已确认适用的强制要求冲突，列“编辑确认”说明冲突，不自行裁决为合规，也不擅自推翻委托 |
| 4 | 已提供的公司/出版社规则或适用规范是否明确要求 | 有明确规则且确实违反 → “明确差错”，即便全稿都一样。稳定使用不自动豁免违规；整稿未遵守也不能仅因次数多改称偏好 |
| 5 | 没有强制条文，是否存在已确定体例或无解释的内部差异 | 合法变体混用、全稿已有格式中的孤立差异 → “体例/一致性”。不能把单个美式合法拼写叫错拼 |
| 6 | 规则适用、义项、要素例外仍有争议 | 语义有合理多解 → “编辑确认”；缺关键原文、版面或工具书资料 → “材料不足”。其余无问题的不列项 |

规则冲突记录 `规则名称/页或条 → 适用对象 → 原文证据 → 冲突及建议`。一般语法、词形和词义错误不能被“全稿一直如此”豁免；表达更自然但原句成立，不报明确差错。不要只因复盘提供了数字和结论就照抄为新报告的事实。

## 必备要素缺失

- 公司规则明确写“每一词条必须标音标”，无缩略语例外，原图 `AI` 条确实缺音标：列“明确差错/词条要素遗漏”，建议按本书读音体例补注，经编辑确定后填写。
- 只知道其他词条有音标，未确定缩略语是否免注：列“体例/一致性”或“编辑确认”，说明“与其余条目不同，请确认 AI 是否属于免注类别”。不能仅凭 1599:1 的数量定硬错。
- 无法看清音标所在位置：列“材料不足”，不猜音标、不从坏文字层推定漏印。反例：规范允许首字母缩略语不标音标且全稿一致，不列项。

## 系统性问题的归并和计数

必须区分：**问题项数**（合并后编号数量）、**出现次数**（已确认位置数量）、**出版差错折算值**（按特定制度计算）。三者不能互换。

同性质且同改法、遍及全书的问题，允许一个范围型条目：`scope.description` 写文件/页或节范围；`occurrence_count` 写次数；`count_status` 写 exact/estimated；`count_basis` 说明是否全量、如何排除英文句内标点/作答线/抽取噪声。`locations` 列若干有页码的样例，无须把数千位置塞入 Word；完整位置表可另存附件并在依据中引用。不同改法/性质分项。

示例：已按适用规则并经版面核实的“中文释义分隔符体例不符”，合并为 1 项，确认出现 36 次，给 3 个定位样例。报告不能写“36 项”，更不能未经规则授权自动乘 0.1。

本技能默认**不计算出版质量差错率或折算分**。用户明确要求计错时，先核手册适用条款、重复差错/全书统一性问题的计法、分母和豁免，另列计分表；条款不明就留待编辑，不杜撰“系统性错误一律算一次”或“一律每处 0.1”。3610 个 `;` 的程序命中数只代表字符数，尚不等于 3610 处违规。
