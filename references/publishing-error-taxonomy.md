# 出版编校差错分类与示例

本文件把常见图书编校差错映射到七至九年级英语教辅，并为各具体类型提供示意例子。例子用于说明核查方法，不代表真实稿件。

**任何经核实的差错都不能存在于交付定稿或付印稿中。**审校时必须逐项报告明确差错，供编辑处理和复核；本技能不直接改动用户稿件。证据不足、存在合理变体或涉及公司政策判断的内容，必须列为“编辑确认”或“材料不足”，不能静默忽略，也不能伪装成确定错误。

## 文字、语言与逻辑

| 具体差错类型 | 示意错误 → 问题说明/处理 | 判定提示 |
|---|---|---|
| 中文题目说明、译文或解析中的错字/漏字/多字 | `请选出正确的答案答案。` → “答案”重复 | 以可读原稿和上下文判断，不因中文表述风格不同判错 |
| 中文语句或逻辑错误 | `本题为单选题，请选择所有正确选项。` → “单选”与“所有正确选项”指令冲突 | 必须指出其对理解或作答的实际影响 |
| 错别字/拼写错误 | `becuase` → 应为 `because`；报告原文、位置和建议拼法 | 英美合法拼法不当作错拼；按英式默认并检查全稿一致性 |
| 漏字、漏词、重字、多字 | `They are are ready.` → `are` 重复；`She went school.` → 可能漏 `to` | 先看上下文和原图，避免把有意重复或 OCR 错识当成原稿错误 |
| 字母颠倒/形近字符混淆 | `teh` → `the`；化学式中的字母 `O` 被误作数字 `0` | 报告实际影响；图像不清则“原图待核” |
| 误用词、词形、词义或搭配 | `The weather is grate.` → 若意为“天气很好”，`grate` 应为 `great` | 结合句义、词性和搭配，不仅凭相似拼写判定 |
| 专名、机构名、地名或作品名错误 | `Londan` → 若指英国首都，应为 `London` | 对照原文或权威来源；来源不明则列编辑确认并注明待核来源 |
| 专业术语/缩写错误 | 把 `e.g.` 解释成“that is” → 该释义对应 `i.e.`，需核对缩写及稿件约定 | 教育、科学、语言学术语须查可靠工具书/权威来源 |
| 语法错误 | `The results is clear.` → 主谓数不一致，通常应为 `are` | 结合主语核心词、语境及英式英语中可接受的结构判断 |
| 句法残缺/成分错误 | `Because it was raining.` 被作为完整独立陈述句 → 在该语境下从句缺主句 | 标明造成残缺的具体结构，不因文体片段而机械判错 |
| 指代不明/逻辑歧义 | `When Anna met Lucy, she was tired.` → `she` 可能指两人中的任一人 | 若题目依赖唯一指代，列明确差错或编辑确认，说明不同解读 |
| 前后矛盾/逻辑错误 | 前文称“所有组员都到场”，后文称“有一名组员缺席” → 同一条件下自相矛盾 | 引出相互冲突的两处原文并分别定位 |
| 无依据的重复内容/重复题 | 同一题干和选项在同一练习中完整重复 → 核查是否误排 | 只有材料足以确认是非设计性重复时才报差错 |
| 外语、音标、重音或转写错误 | `ship /ʃiːp/` → 若目标词是 `ship`，音标元音与词不符，通常应核为 /ɪ/ | 依据采用的词典/音标体系核验；允许的转写变体不判错 |
| 其他外语拼写、词形或语法错误（如适用） | 例句中法语动词变位与主语不一致 → 对照对应语种规范核查 | 稿件出现其他语种时才检查；能力或资料不足时列编辑确认 |
| 拼音、声调或其他文字转写错误（如适用） | 目标词声调为第三声却标成第一声，例如 `mǎ` 误作 `mā` | 仅稿件确有此类内容时检查；按权威词表或指定体系核验 |
| 合法拼写/格式变体混用 | 同一稿件中 `colour` 与 `color` 混用 → 单项均可成立，但英式英语体例不统一 | 归“体例/一致性”，不得把单项合法拼法判成硬错误；按公司规则统一方向 |
| 大小写错误 | 普通句中星期名 `monday` → 应大写为 `Monday` | 按英语规则、专名和标题体例区分 |
| 斜体/正体误用 | 题目要求识别斜体词，但排版把目标词排成正体，导致无法识别考查对象 | 只在版式可见且影响阅读/答题或违反明确体例时报告 |

## 事实与内容专项核查（仅在用户明确要求时启用）

| 具体差错类型 | 示意错误 → 问题说明/处理 | 判定提示 |
|---|---|---|
| 事实、科学或概念错误 | `A square has three sides.` → 正方形有四条边；这是可核验的概念错误 | 查用户提供材料或权威来源；报告核验依据，不凭印象下结论 |
| 政治、历史或公共议题表述错误/导向疑点 | 稿件把某历史事件的时间、人物关系或结果写反 → 事实表述错误；价值导向判断需依据规范 | 事实核查引用权威原始资料；涉及导向/政策判断且规范不明时列编辑确认 |
| 法规、标准、文献或出处引用错误 | 稿件称“某标准第 4 条规定 X”，而所引标准第 4 条实际无此内容 → 引文与来源不符 | 对照原始正式文本，报告版本/条款/访问日期；来源不可得则列编辑确认 |
| 计算、公式或推导错误 | `12 ÷ 3 = 5` → 运算结果错误；或解析步骤不能推出所给结果 | 复算并复核单位、符号和步骤；数学/科学专门内容超出把握时列编辑确认 |
| 过时标准、数据、名称或时效信息 | 稿件称某已废止标准“现行有效” → 需查官方标准平台的状态和替代信息 | 记录查询日期和官方来源；历史语境中准确引用旧信息不自动算错 |
| 可能伤害未成年读者/不适龄的内容 | 示例句对自伤、危险模仿行为作鼓励性表达 → 标出原句及具体风险，交编辑核查 | 以适用规范、公司政策或可靠依据支持；无明确依据时列编辑确认，不擅自改写或定性 |
| 群体、宗教、民族、地域或文化刻板化/歧视表达 | 示例句将某群体描述为“天生都……” → 可能形成一概而论的刻板印象 | 用中性描述指出具体措辞和风险；按适用规范与编辑政策核查，疑点列编辑确认 |

## 题目、答案与解析（默认核查范围）

| 具体差错类型 | 示意错误 → 问题说明/处理 | 判定提示 |
|---|---|---|
| 题干条件缺失/错误 | `Find x: 2x + 1 =` → 等式不完整，无法求解 | 说明缺少或冲突的条件及其对作答的影响 |
| 题目无解或多解 | `Choose the correct word: I have ___ water.` 选项含 `little` 和 `a little`，但语境未提供正负数量意义 → 可能不唯一 | 逐项验证；如果不同合理解读均成立，列编辑确认，不擅自选定答案 |
| 选项错漏/题干与选项不匹配 | 题干问“Which animal…?”，选项全为颜色 → 选项不能回答题干 | 记录题干和全部相关选项 |
| 答案错误 | 题目为 `6 × 7`，答案表给 `48` → 正确结果为 `42` | 回查题目和答案页，确认不是题号错位 |
| 答案缺失或错位 | 第 8 题无答案；答案表第 8 题答案实际对应第 9 题 → 标明受影响题号 | 对照整页答案表，不能只看单条 |
| 解析与答案矛盾/推理错误 | 解析写 `6 × 7 = 42`，末尾却选 `C (48)` → 推导和结论冲突 | 同时引用关键推导与答案结论 |
| 解析引用材料错误 | 解析说原文人物 `arrived on Friday`，所给原文写 `Saturday` → 引文或依据不符 | 标出原文位置和解析位置 |
| 题目重复或题号/选项编号错误 | 题号从 6 跳到 8，或同页两题都标为 7 → 核对漏题/重号 | 记录连续编号、目录或答案表的对照证据 |

## 公共标识与服务信息（出现时纳入语言/术语核查）

| 具体差错类型 | 示意错误 → 问题说明/处理 | 判定提示 |
|---|---|---|
| 核心意义反转/遗漏 | 标识原文“请勿入内”，译文 `Please enter.` → 否定指令被反转，可能导致读者采取相反行动 | 这是功能意义明显冲突的示意例。实际报告须确认原文、标牌用途和页面图像；具体译词要求按[公共服务英文参考指引](public-service-reference-guide.md)查正式文本 |
| 场所或设施名称误译 | 校园导向题把“图书馆”译成与场景不符的设施名称 → 目的地信息可能错误 | 先确认该词是普通名词、机构正式名称还是标识译名；不以逐词直译或模型记忆判断 |
| 题目把允许变体设为唯一答案 | 翻译题要求唯一译法，但适用标准列出多个译法或场景条件不足 → 唯一答案依据不足 | 核对对应分册和具体条目；标准文本无法取得或上下文不足时列“编辑确认/材料不足” |

公共服务标准只直接适用于其覆盖的标识/服务信息及明确要求按标准译写的题目。普通英语文章中的引文或叙述不因含同一词语就自动成为标识；只在官方名称、设施称谓或领域术语上借鉴，不能把标识语体推广为普通文章规则。

## 图表、数字、符号与引用（与题意/答案相关时默认核查）

| 具体差错类型 | 示意错误 → 问题说明/处理 | 判定提示 |
|---|---|---|
| 正文与图/表/图注不符 | 正文称图中比例为 `15%`，图表数据标为 `51%` → 数值冲突 | 并列记录正文与图表位置；先确认是否有说明性差异 |
| 图像与标题/标签不符 | 猫的图片标注为 `a dog` → 图文对象不符 | 只有能看清图像时作判断；模糊图像列材料不足 |
| 日期、时间、数值或比例错误 | `31 June` → 日期无效；正文写 `50%` 而表格写 `15%` → 数据不一致 | 事实型数值需查来源；内部不一致须指出两处证据 |
| 数字编号、阿拉伯/罗马数字错误 | 标题为 `Chapter III`，正文交叉引用却称本章为 `Chapter II` → 编号不一致 | 只有影响检索、意义或违反明确体例时报告，不把纯偏好判错 |
| 字母/数字/符号混淆 | 选项 `O` 与数字 `0` 混排，导致答案索引不清 → 核对字符及题意 | 扫描件须回看原图；无法判断时标定位不确定 |
| 标点、括号、撇号错误 | 独立问句 `Where are you going.` → 句末应使用问号 | 英文与中文均按公司体例及句法判断；不把合法变体当错 |
| 注释、题注、公式/图表/脚注序号错误 | 正文写“见图 3”，实际说明对应图 2 → 交叉引用错误 | 核对文内引用与实际编号/目标内容 |
| 单位或科学符号错误 | 某段把长度记作 `5 kg` → 千克是质量单位，量纲与文字不符 | 涉及专业规则时查权威来源；不能确认则列编辑确认 |
| 音乐记号错误（如适用） | 谱例标注音名为 C，但图中对应音符标为 D → 标注与谱例不符 | 仅稿件含乐谱/音乐符号时检查，按稿件指定体系核验 |

## 格式、排版与文件呈现

| 具体差错类型 | 示意错误 → 问题说明/处理 | 判定提示 |
|---|---|---|
| 空格、段落或分隔错误 | `infrontof` 被排成一个词，或两个题目粘连且题界不清 → 影响词形/题目辨认 | 区分源文件错误与 PDF/OCR 提取造成的问题 |
| 英文断行/断词错误 | 版面把 `reading` 断成 `re ading`，造成词形破坏 → 检查断行 | 合法的行末连字符/排版换行不自动判错 |
| 分页、分栏、漏项或重项 | 选项 D 被分页/分栏隐藏，或解析正文被重复拼入下一栏 → 题目不完整/错乱 | 需查看页面渲染；纯文本无法确认时注明未查版面 |
| 字体、字号、颜色、标题层级不一致 | 同级题目标题一处 14 磅、一处 16 磅，且公司模板规定同级统一 → 体例不一致 | 以公司规范或可证实的整稿体例为准；无规定时不臆造标准 |
| 图表、标题、符号或答案位置错误 | 表格标题落在另一张表上，或答案标记排到相邻题目下 → 可能误导对应关系 | 记录可视证据及受影响题号/图表 |
| 页码、页眉页脚、题目/答案交叉定位错误 | 正文写“见第 12 页”，目标内容实际在第 13 页 → 引用失效 | 需查看完整文件；只提供部分页面时列材料不足 |

上述类别按稿件内容适用：稿件没有音乐记号、拼音或特定版面要素时，不为凑类别而虚构检查结果。事实与内容专项核查不属于默认任务；只有用户明确要求时才启用。**任何确定错误都必须报告；对有证据冲突或依据不足的项目，必须显式列为“编辑确认/材料不足”，不得静默忽略，也不得假装已经核实。**

## 范围边界

默认范围是中英文语言差错、题目/答案/解析及与作答直接相关的图表和数字。教材版本同步、课程标准符合性、年级难度、外部事实真伪/时效和内容政策审查，只有用户另行要求时才启用。启用外部核查后，只有能给出可追溯依据时才作确定判断；来源缺失、相互冲突或涉及公司政策取舍时，列编辑确认。

本技能的“影响等级”和“置信度”是便于编辑排序的报告标签，不是 CY/T 266—2023 的差错分值，也不用于计算图书编校差错率。
