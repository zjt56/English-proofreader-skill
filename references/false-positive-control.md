# 误报控制与规则校例

用正反例区分真实差错与合法形式；候选须回到原文、题型和语境中判断。字体异常查第二节，维护/验收方法仅在调教技能时使用。

## 正反例护栏

判断稿件时，应把下面两类例子一起考虑。若一个形式在合理语境或指定体例下成立，不得仅凭表面模式标为明确差错。

| 检查点 | 应报告的候选错误 | 不应直接判错的反例/处理 |
|---|---|---|
| 拼写 | `becuase` → `because`：明确错拼 | `colour` / `color`：分别是合法拼法；同一英式稿件混用时列体例/一致性，不把单项判成错拼 |
| 助动词与动词形式 | `She doesn't likes apples.` → 助动词后动词形式错误 | `She doesn't like apples.` → 正确形式，不应因 `like` 没有词尾变化而报错 |
| 主谓一致 | `She go to school.` → 在一般现在时普通陈述句中主谓不一致 | `The team are celebrating.` → 英式英语中可按成员整体理解使用复数，结合语境判断，不机械改为单数 |
| 句子片段 | 将 `Because it was raining.` 当作完整独立陈述，且上下文无主句/对话回应功能 → 候选残句 | 对问题 `Why did you stay home?` 回答 `Because it was raining.` → 对话中可以成立；必须看上下文 |
| 词义/答案唯一性 | 空格题没有语境，但将 `little` 与 `a little` 设计为唯一答案 → 题目可能不唯一 | `I have little water` 和 `I have a little water` 均可成句，语义不同；不能把其中一个词组本身判为语法错 |
| 引号与标点 | 标点导致句法边界错误、问句误作陈述或括号未闭合 → 报具体影响 | 英式与美式引号内标点位置可能有体例差异；无明确规定时查全稿一致性，不凭单例判硬错 |
| OCR/形近字符 | `O` 与 `0` 混淆且改变选项/数值 → 回看页面图像 | OCR 文本显示错误但原图正确 → 这是识别噪声，不是稿件错字；原图无法辨认则标材料不足 |
| 题目横线/下划线 | 只有在横线遮挡文字、长度/位置造成题意或作答异常时才报告 | 选择题 A/B/C/D 之间的排版横线、填空题留出的下划线、括号后的答题线、题号后的空白线都是作答区域，不是英文标点空格或缺字；不得把它们与逗号/分号拼接成错误 |
| 选项与填空区 | 选项字母、选项文字顺序与题干不对应，或答题线覆盖/截断选项 → 报题目/版面问题 | `A. ... B. ... C. ... D. ...` 是选择题选项；括号、下划线和长横线表示待填位置。不能把选项之间的空白、下划线或括号内空白报告为语法、标点或空格错误 |
| 事实核查 | 明确事实主张与可追溯的权威原始来源冲突 → 附来源和查询日期报告 | 事实依赖时间、上下文、定义或地域时，不用模型记忆直接判错；需核对对应来源或列编辑确认 |
| 公共服务标识译文 | 标识原文“请勿入内”，译文 `Please enter.` → 否定意义反转，作为明确的翻译差错候选；需记录标识场景及图文位置 | 普通叙述 `The notice said, “Please enter.”` 的句子语法不由公共标识标准判定；先判断文本功能，再按[公共服务英文参考指引](public-service-reference-guide.md)查适用分册。需要标准依据时查适用的正式条目，不确定的标牌场景/译法列编辑确认 |

## 字体编码异常与音标字符

PDF 子集字体/ToUnicode 映射可能使可见的正常字形抽成 PUA（私用区）、ASCII `I` 或其他编码。PUA范围为 U+E000–F8FF、U+F0000–FFFFD、U+100000–10FFFD；这些码位没有可通用于所有字体的固定语义。字体名相同也不保证跨文件字形映射相同。

判断分支：先查原页字形 → 比对同文件同字体的已知词/音标 → 若可证是映射问题，记读取诊断，语言审校使用已核对的可见字形；图像看不清则材料不足。`U+0049` 在普通英文里是正常大写 I，不可全局改成 /ɪ/。复盘里的 `U+100C79=ɡ` 等只能作为特定字体的待核线索，不能固化进通用替换表。

如需临时映射，必须绑定 `源文件哈希+字体名+码点+原图证据`，保留原提取值和映射值，不改原稿。`􀪋` 等重复长线也可能是装饰字形，先看版面功能；PUA计数不是音标差错数。脚本的 encoding_diagnostics/auxiliary_lines 只是读取诊断，不自动进入 issues。

英式词典常见音标核查白名单（仅作识读辅助，不是穷尽的合法字符集合）：

- 元音：`iː ɪ e æ ɑː ɒ ɔː ʊ uː ʌ ɜː ə eɪ aɪ ɔɪ əʊ aʊ ɪə eə ʊə`。
- 辅音：`p b t d k ɡ g f v θ ð s z ʃ ʒ h m n ŋ l r j w tʃ dʒ`。
- 标记：主重音 `ˈ`、次重音 `ˌ`、长音 `ː`、音节点、`/ /`、`[ ]`、括号（如 `(r)`）、连读/弱读和词典规定的其他标记。

不在表内的字符只能触发“核字形/查本书音标体系”，不能据此判稿件错误；`ɛ`、`ɹ`、`ɚ`、`ɝ`、`ɐ` 等可能属于另一套合法转写或变体。音标须连同词头、重音、词典体例整体核对，不能逐字符从不同词典拼一套“正确音标”。

## 维护与模型验收（调教时使用）

- 每条新规则至少留一组“应报/不应报”相似例句，注明语境和体例；改规则后两类一起检查。编辑确认案例经授权、匿名化后再收录，不将单例变成通则。
- 用编辑预标的陌生材料盲测：覆盖拼写语法、答案解析、合法变体、材料不足，以及PDF/图片、多栏表格、跨页和低清字符。
- 记录模型/版本、日期、输入类型、是否可看原图、批次和指令版本；核漏报、误报、原文及定位、解题解析、实际阅读遍数与报告/Word一致性。
- 先修复高频误报、漏报和定位问题。调试集与保留盲测集分开；不把盲测答案放进公开技能，不用提示词长度或模型自称决定是否通过。
