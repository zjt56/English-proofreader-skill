# 出版参考资料使用指引

本文件只说明遇到什么问题应查哪类资料，不收录规范原文、识别摘录、本地资料路径或历史识别质量记录。技能中的核查清单是执行提示；涉及特定规范的结论，以任务中可核实且适用的依据为准。

## 按疑点选资料

| 遇到的问题 | 应参考的内容 | 应核实什么 |
|---|---|---|
| 公司流程、校次交接、必备项目、计错要求 | 用户提供的木牍编辑手册或本次公司体例 | 适用版本、指定范围、例外；正式流程以公司规定为准 |
| 拼写、词性、义项、搭配、词形、音标 | 可靠的英式英语学习词典、语法工具书 | 完整词条、词性与义项归属、语境和英美变体；不只看搜索摘要 |
| 中文内夹英文的标点、空格、正斜体、换行 | 中文出版物夹用英文的编辑规范，如 CY/T 154 | 中文外层和英文内部的适用区别；不把某一排法用于所有英文材料 |
| 中文标点、数字、计量单位和符号 | 相应出版标准、学科规范及公司体例 | 是否适用、是否允许多种写法、全稿是否一致 |
| 英文标点、引号、连字符、大小写 | 英式英语标点/写作工具书及公司体例 | 功能、句法、体例和可接受变体 |
| 公共标识、设施/机构名、公共服务译写 | [公共服务参考方向](public-service-reference-guide.md)所列主题 | 文本功能、使用场景、正式名称；需要时核对对应标准 |
| 目录、索引、题号、答案、解析、图表引用 | 当前同版稿件中的对应内容及已确定体例 | 版本、分组、页码基准、收录范围、上下文；优先内部交叉核对 |
| 差错类别、出版计错或质量评价 | 适用的差错认定办法和公司质量要求 | 计数单位、归并办法、适用范围；不从命中次数自行折算分值 |

## 使用办法

1. 先凭完整上下文和稿件内部对应判断；有具体疑点才查对应资料，不要求先读一整套规范。
2. 查词条和语言规则用于本次编校；外部事实、教材同步、年级难度等仍依用户授权范围执行。
3. 若要引用具体条文、声称某译法为标准答案或宣称标准现行，核对正式来源、版本与适用条件。未核对就不写条文号、精确引语或强制性结论。
4. 能由句内规则确认的明显差错正常报告。只有结论确实依赖缺失的体例或条文时，才列“编辑确认/材料不足”，说明需要确认什么。
5. 规范冲突、系统性问题、必备要素遗漏按 [判定表](editorial-adjudication.md)处理。其他技能的提示语和工具建议不作为出版规范。

本指引可随技能用于本地或云端；实际任务提供的资料是核验依据，不要求访问开发机器上的资料目录。
