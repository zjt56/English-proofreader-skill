# 出版规范参考资料索引

本技能只收录足以改变审校判断的规则摘要和检索路径，不复制整套手册。引用标准具体条文、判定现行状态或使用某一条标准译文时，须核对正式文本和版本；模型记忆、OCR 抽取和本索引都不能代替原文。

本索引中的 `MD/...` 路径用于记录本地整理资料的来源，不是云端运行依赖。云端使用时以技能包内的规则摘要和下方官方来源为入口；若无法取得标准正式文本，不得把本地 OCR 摘录当作确证。

## 适用顺序

1. 用户本次明确的范围、编辑决定和公司体例。
2. 与稿件类型和内容直接相关、经核对版本的现行标准及正式来源。
3. 稿件已经稳定形成的体例；存在规范冲突时交编辑确认，不由模型自行改定。
4. 本技能的英式英语和一般编校参考规则。

公共服务英文译写规范属于本技能的定向术语参考：遇到公共标识、设施名称或按标准编写的翻译题时主动检索相应分册。普通英语文章只在涉及同领域专名、设施名或标准术语时参考，不把标识语体、标题大小写或特定句式套到普通叙述文。

## Markdown 原文的可靠性

`MD/00-索引.md`、`MD/00-核对报告.md` 和 `MD/00-校对日志.md`记录了抽取来源和已知偏差。主要限制如下：

- 《2021木牍教育编辑手册》是 PDF 文字层与 OCR 混合；第 21 页复杂流程表被串行，页码也是 PDF 页序。用它提取文字找规则时，应以原 PDF 页图确认表格和易混数字。
- 十个 GB/T 30240 分册均为扫描 OCR。抽检发现交通分册的英文译词单元格有空格丢失，标点、加号、标准编号和字母也有混淆风险。OCR 结果可用于搜索词条，不可单独作为“标准原文”证据。
- GB/T 15834—2011 和夹用英文标点草案均为扫描 OCR，小标点、引号和破折号存在漏识风险。该草案只作背景材料，不表述为正式强制规则。
- CY/T 154—2017及《英语标点符号用法》（Penguin）多数页面有文字层；本地抽检质量较好，但已知专名和 OCR 页仍需回看原 PDF。
- 《图书编辑校对实用手册》扫描中存在双页合一和多列表格错序。没有对应页图时，不据 Markdown 还原表格内容或精确页码。

报告中的稿件问题必须以稿件原图/可靠正文为证；本地资料中的 OCR 错误不能复制成审校规则或标准引文。若源文件不可访问、标准全文不可核对或不同版本冲突，列明资料限制并交编辑确认。
