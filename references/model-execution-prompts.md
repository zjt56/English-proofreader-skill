# 分批调用的短指令

仅在需要把工作拆成多次模型调用时使用。每次只带当前原稿、相关材料和少量适用规则；不要复制整套参考资料。正式校次由主任务按 [木牍流程](mudu-three-review-three-proof.md)管理。

```text
稿件/版本：{来源标识}
范围与结构：{原文件页/题组/Day/附表；关联材料}
本轮：{初检／独立复读／冷读后候选复核／明确指定的正式环节}
适用规则：{本次实际相关的规则或章节}

按SKILL.md的四步处理本批，只报告，不改原稿。
完整阅读本轮范围；独立复读和冷读先不看旧台账，冷读后再逐条复核候选。
先核组内编号与对应，再核语言；题目先作答后对答案解析，词表核词性义项和词形。
答题线、干扰项、合法变体和抽取编码问题先按功能排除。
每项给来源、原文件页、题号/词条、原文、类型、具体错点和最小建议；不确定就说明待确认什么。
返回候选及真实已读范围、遍数和待核点，不预填其他批次/轮次完成，不虚构工具运行。
```

主任务合并候选，按 [输出规范](output-format.md)交付；使用脚本时再查 [机器字段](report-schema.md)。复读只能登记为复读，不能升级为正式校次。
