# 公共服务领域英文译写索引

稿件出现公共标识、设施/机构名称、公共服务指引，或题目明确要求按公共服务规范翻译时，先按主题选用对应分册。普通英语文章只有在出现相关专名、设施称谓、官方译名或标准术语时才调用本索引；标准译写规则不能取代普通文章的语法、语体和上下文判断。

国家标准全文公开系统在 2026-10-21 查询时列出十个分册均为现行推荐性国家标准。正式状态和文本可能更新，实际核查时重新查[官方标准检索页](https://openstd.samr.gov.cn/bzgk/std/std_list?p.p1=0&p.p2=%E5%85%AC%E5%85%B1%E6%9C%8D%E5%8A%A1%E9%A2%86%E5%9F%9F%E8%8B%B1%E6%96%87%E8%AF%91%E5%86%99%E8%A7%84%E8%8C%83&p.p90=circulation_date&p.p91=desc)。

## 通则检查面

按 GB/T 30240.1—2013 的适用范围，重点判断：

- **意义和功能**：译文是否准确表达中文意图；设施名称、方向指示、警告、禁止、请求和操作说明是否区分。标识语通常按功能和英语公共信息习惯表达，不能只逐字替换。
- **场所/机构名称**：拆分专名、通名和限定成分，核对专名采用拼音、已有英文名或意译是否有依据，通名是否表达设施类别。不得凭模型记忆改动已确定的官方名称。
- **英文使用**：拼写、词语选择、语法、单复数、大小写、缩写、空格、标点和断行应符合英文习惯并保持同一标识系统一致。
- **清晰与可用**：公共提示应便于目标读者理解；否定、警示等级、方向、位置和适用对象不能在翻译中丢失或反转。
- **学校场景**：教育分册特别覆盖学校/教育机构名称和学校服务信息。学校名称中的 `University`、`College`、`School`、`Institute` 等不能按字面机械替换，应结合机构类型、正式名称和分册规定核实。

## 执行步骤

1. 先确认这段文字是否真是公共标识/服务信息，还是普通文章中的叙述或引文；记录场所、读者、使用功能和原文含义。
2. 依据主题选择分册；查正式标准的正文或附录译法，不把搜索摘要或模型记忆当作标准原文。
3. 将稿件译文与标准条目逐项对照，同时检查上下文是否匹配标准条目的具体适用场景。标准列出多个译法或条件分支时，不擅自只保留一个。
4. 若题目声称只有一个标准答案，而正式标准允许多个译法、语境缺失或标牌用途不明，列“编辑确认”，说明需补足的条件。
5. 报告引用具体标准时，记录标准号、部分/条目或附录表号、官方来源和查询日期。只借用领域术语但未核验正式条目时，不声称“违反标准”。

## OCR 与引用限制

本地十个分册均为扫描 OCR。`MD/00-核对报告.md`指出英文术语表存在词间空格丢失，其他已记录的问题还包括加号/汉字、字母、编号和标点误识。因此，本地 Markdown 仅用于全文搜索和定位候选词条。引用英文原句、断定空格/标点或确认表格行列前，必须回看原始 PDF 页图或官方可读文本；拿不到时列“材料不足”，不能依据 OCR 结果定错。

不要把本标准扩展为普通英语文章的总语体规范、教材难度要求、文化审查或事实核查。只有题目或用户明确要求时，才增加这些任务。
