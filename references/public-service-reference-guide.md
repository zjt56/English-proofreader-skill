# 公共服务英文的参考方向

遇到公共标识、服务指引、机构/设施称谓及相关翻译题时，先判断文本用途，再决定需要查什么。不收录标准译词表、原文摘录或本地资料索引。

| 内容场景 | 可参考的主题 |
|---|---|
| 警告、禁止、方向、出入口、操作提示、机构命名 | 公共服务译写通则；意义、功能、语气、名称构成及书写一致性 |
| 车站、道路、线路、交通提示 | 交通服务设施、指引和安全用语 |
| 景区、导览、游览服务 | 旅游场所与服务用语 |
| 博物馆、剧场、展览、文化活动 | 文化娱乐设施和公共信息 |
| 场馆、体育设施、赛事指引 | 体育公共服务用语 |
| 校园、教学楼、实验室、教育机构 | 教育设施与机构称谓 |
| 医院、科室、卫生提示 | 医疗卫生公共信息 |
| 邮局、通信设施、邮寄服务 | 邮政电信服务用语 |
| 菜单、餐饮服务、酒店、住宿设施 | 餐饮住宿用语 |
| 商店、银行、支付、商业设施 | 商业金融服务用语 |

需要标准依据时，可按主题查 GB/T 30240《公共服务领域英文译写规范》的适用部分；不预先断言版本或状态。机构/设施有正式英文名时，核其来源和实际对象。

审查顺序：辨认场景与原意 → 核否定、对象、方向及功能是否表达正确 → 检查英文语言 → 必要时查正式名称或对应标准。标准支持多个译法或缺少场景时，列明条件供编辑确认。不能把流畅程度不同直接判成译错。

普通文章仅在相关名称或术语有疑点时参考这些主题，不套用标识的简短指令语体。报告声称“违反某条标准”时，应有可追溯的正式条款依据；一般语义反转或语法错误可按实际语言问题说明。
