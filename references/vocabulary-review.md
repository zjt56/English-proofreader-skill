# 词表、索引和附表专用审校

只在存在词条/词形表时读取。保留基本拼写、语法和标点检查；无题目时跳过独立解题，无答案表不构成材料不足。

## 先结构，后语义，再反查

1. 确认目录、索引、正文和附表的版本关系、文件页与印刷页映射及收录范围。
2. 按版面提取带来源/位置的结构记录，先核条数、分组、阅读顺序；文字层的栏序/编码异常先修读取路径，不报稿件错。
3. 批量核目录起始页；索引词头与正文词头双向比对、逐条核指向页；按 Day/节核序号；附表核行列及正文复现一致。脚本契约见 [结构校验](structured-checks.md)。未运行脚本时由模型做同项核对，不能虚构“程序已核 1600 条”。
4. 语义审校按 Day、字母段或完整附表处理。核每条的词头、音标、词性、释义、派生词、短语、例句和词形关系，不因结构检查通过而省略。
5. 所有结构不匹配项回到对应原页；“找不到”先查跨栏/跨行、可接受变体、收录口径和版次，不直接定漏词。

## 词条判据与正反例

| 检查项 | 应报告的例子 | 不得误报/进一步确认 |
|---|---|---|
| 词头 | `enviroment` → `environment`，原图确实漏 n | `colour` / `color` 均是合法词形，依英式体例判断混用；`leave ou` 原图完整不报 |
| 词性与义项 | `advice v. 建议`：该词条作“建议”名词，应核 `n.`，或是否原词应是 `advise` | 多词性 `record n./v.` 可合并，但各释义须与所标词性对应；不能因一词多义就判错 |
| 义项归属 | `borrow v. 把……借给别人` 与通常的“借入”方向冲突，核上下文后建议“借；借入” | 短释义可省修饰、合并相近义，但不能反转施受方向、否定或动作主体 |
| 短语与派生词 | `take away n.` 若实际意指外卖名词，核 `takeaway`（英式）或短语词性/释义编排 | “带走食用”可能描述 `take away` 的动作，不能只见“外卖”二字就断定混入名词。核是否表示动作、食物、店铺，是否有词性和例句支持；仍不明列编辑确认 |
| 词形 | `teach—teached—teached` → 核 `teach—taught—taught` | `learned/learnt`、`dreamed/dreamt` 等变体按工具书与英式体例，不删合法变体 |
| 音标与重音 | 原图同一词条的音标确属另一词，或已确认漏必备重音，列具体字符及建议 | `I`、私用区码、直撇号可能是字体映射；`(r)`、长短音及弱读依词典体例，不能混合两套音标逐字对错 |
| 例句与中译 | `He enjoys to swim.` → `He enjoys swimming.`，解释非谓语错点 | 词条短语和省略式释义不是完整句，不强补冠词/主语；例句中故意展示错误用法先看标注 |
| 必备要素 | 明文规定词性必注而 `advice` 条漏注，报告“词条要素遗漏” | 缩略词音标等是否免注依 [判定表](editorial-adjudication.md)，不从多数体例自动推出强制规则 |
| 索引收录 | 全收主词条的既定范围中确实漏 `apple`，核原页后报告 | 只收主词头的索引不必收全部派生/例句词；同词不同词性可能合法重复 |
| 附表 | 不规则动词表同一行被错移成另一动词的过去式，报告行列与对应改法 | 不能把视觉四列自动当成四段文章；`原形/过去式/过去分词/释义` 应逐行对应 |

判断词义先拆 `词头 → 词性 → 义项 → 例句/中文 → 本书收录层级`，再按 [判定表](editorial-adjudication.md)定性。基础语言知识可用明确规则；罕见义项、短语/派生词混合、工具书间分歧须查可追溯词典条目（记录词性/具体义项，网络查询注明链接和日期），或列编辑确认/材料不足。工具书查询是语言核验，不扩展为教材难度或外部事实审核。严禁编造词典引文。

## 高密度稿件分批

结构核对可一次处理全套已验证记录，不按每页重开一批。语义批次优先用“第 1–3 天”“A–B 段”“附表 1”，每批保持完整词条及跨页续接；先试一批，根据文本量/图像清晰度缩放。模型弱或上下文紧时用 1 天/小字母段，可靠文字可多天。1–2 页仅是图像难读时的起点，不是固定硬限，更不乘以三个出版校次。每个批次只把相关条目与所需短规则交给模型，保留共享目录/页映射和前后续接信息。
